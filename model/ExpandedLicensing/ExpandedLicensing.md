# ExpandedLicensing

## Summary

Fully expanded license expressions.

## Description

This profile supports representing a fully expanded
[license expression](../../annexes/spdx-license-expressions.md)
in object form.

## Metadata

- id: https://spdx.org/rdf/3.0.1/terms/ExpandedLicensing
- name: ExpandedLicensing

## Summary @ja

`ExpandedLicensing` プロファイルは完全な表記として展開されたライセンスを定義する。

## Description @ja

`ExpandedLicensing` プロファイルは、完全な表記として展開された[ライセンス形式](../../annexes/spdx-license-expressions.md)をオブジェクト形式で表現することをサポートする。
